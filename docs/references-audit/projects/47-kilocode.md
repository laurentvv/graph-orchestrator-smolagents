# 47 — kilocode

- **Nom** : Kilo Code (`kilocode`)
- **Chemin** : `references/kilocode/`
- **Type** : Plateforme d'agent de coding multi-surface (CLI / TUI / VS Code Extension / JetBrains Plugin / Agent Manager) — fork d'OpenCode enrichi d'orchestration multi-sessions (worktrees git), mémoire persistante, sandbox bubblewrap, compaction arborescente et exécution confinée CodeMode.
- **Langage principal** : TypeScript / SolidJS / Effect-TS (monorepo Turborepo + Bun workspaces, 35 packages) ; 9 274 fichiers hors `.git/` : 4 364 `.ts`, 1 325 `.svg`, 958 `.tsx`, 598 `.kt` (plugin JetBrains), 587 `.png`, 504 `.md`, 228 `.json`, 225 `.css`.

## Synthèse
Kilo Code est une plateforme d'agent de coding complète et modulaire construite comme une extension majeure d'OpenCode. Son architecture articule un moteur central CLI/serveur en TypeScript (`packages/opencode/`, exposant une API REST + flux d'événements SSE via Hono et un runtime Effect-TS), piloté par des interfaces variées (TUI SolidJS/OpenTUI, extension VS Code `packages/kilo-vscode/`, plugin JetBrains `packages/kilo-jetbrains/`). Au-delà du simple agent interactif, Kilo Code intègre l'**Agent Manager**, un sous-système d'orchestration de sessions parallèles isolées dans des git worktrees indépendants.

Pour `graph-orchestrator-smolagents`, Kilo Code constitue une référence de premier plan sur plusieurs de nos priorités clés :
1. **P12 (Scopes & Isolation) & P3 (Anti-loop)** : Le gestionnaire de worktrees (`WorktreeManager`) et l'orchestration multi-sessions permettent d'exécuter des sessions de génération et de test en parallèle dans des répertoires isolés (`.kilo/worktrees/`) sans polluer l'espace de travail principal, avec support du multi-versioning (jusqu'à 4 versions concurrentes pour un même prompt).
2. **P9 (Compaction de contexte & Reducers)** : Kilo Code résout deux écueils majeurs des historiques LLM massifs : le sauvetage automatique lors des dépassements de payload (`KiloCompactionPayloadRecovery`, qui convertit les screenshots/médias en placeholders textuels et purge les sorties d'outils obsolètes) et la compaction hiérarchique récursive par chunks (`KiloCompactionChunks`) lorsque l'historique excède la capacité d'une passe unique.
3. **P8-bis (Sandbox) & P8 (Middlewares & Confined Execution)** : Le package `codemode` fournit un interpréteur JavaScript confiné par analyse AST (`acorn` + `typescript`) avec budgets stricts (timeout, max tool calls, max output bytes) et diagnostics typés (`DiagnosticKind`), permettant au modèle d'enchaîner des outils de façon programmatique sans risquer d'échappement. En complément, `kilo-sandbox` implémente une isolation filesystem sous Linux via Bubblewrap (`/usr/bin/bwrap`) et Seccomp.
4. **P6 (Judge & Diff) & P11 (Mémoire & Télémétrie)** : Le système de mémoire structurée `kilo-memory` organise les faits durables dans des fichiers markdown dédiés (`project.md`, `environment.md`, `corrections.md`) avec digest borné (4KB) et traçabilité des décisions (`MemoryDecisions` accepted/skipped/fallback). Le calcul de diff git natif (`DiffFull.batch`) par tranches de 500 fichiers contourne la limite Windows de 8 191 caractères tout en évitant les blocages des algorithmes JS de diffing en mémoire.
5. **P0-bis (Invariants) & P10 (Skills)** : Le garde-fou `ConfigProtection` interdit formellement au modèle de modifier ses propres fichiers de configuration (`kilo.json`, `AGENTS.md`, `.kilo/`) sans validation humaine, tandis que la validation de skills (`trustedInProject`) neutralise les escalades de privilèges via liens symboliques.

Réserves : Le code est fortement typé autour de TypeScript et du framework `Effect-TS`, ce qui implique un portage conceptuel et algorithmique vers Python plutôt qu'un copier-coller brut. De plus, une partie significative du monorepo concerne les interfaces graphiques (SolidJS, Webview VS Code, JetBrains Swing/Kotlin) qui sont hors du scope de notre usine backend. Note globale : **🟢 Haute** — mine d'or pour la robustesse de la compaction, l'isolation par worktrees, la sandbox d'exécution et la protection des fichiers de gouvernance.
