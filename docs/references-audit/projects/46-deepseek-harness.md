## Synthèse
Harness d'agent de coding de DeepSeek AI dont la valeur ne réside pas dans le code (TypeScript/Cordis, non réutilisable tel quel en Python) mais dans des **mécanismes de loop ultra-documentés et testés**, avec un design invariant-driven : chaque package a un `invariant.ts` exécutable, les décisions sont tracées en ADRs (`.agents/notes/`), et chaque sous-système a sa doc (`docs/subsystems/`). Le cœur : `packages/core/` (session log append-only, system-prompt assemblé par sections, tool registry, `ReactLoopAgent`), étendu par plugins — `llm/` (adapters, retry), `compaction/`, `skill/`, `guard/` (anti-boucle), `workflow/` (dont l'outil `ralph` = boucle à agents frais), `subagent/`, `session/` (persistance JSONL/SQLite + télémétrie OTel).

Pour `graph-orchestrator-smolagents`, c'est **la meilleure référence de design sur 6 de nos priorités** : P3 (deux mécanismes anti-loop complets et lisibles : détecteur de répétitions consécutives + boucle ralph à agents frais), P8 (retry durable dont le compteur survit à un crash + parsing streaming tolérant + pipeline documenté de 5 waterfalls d'exécution d'outil), P9 (compaction par checkpoint structuré en 8 sections + pruning déterministe model-free + comptabilité « shadow price »), P10 (skills lazy par couches scopées), P11 (event log typé extensible avec provenance — supérieur à la plupart des harness), P0-bis (l'AGENTS.md racine est une charte d'invariants remarquable : « Registrations are effects », « Model-visible ⟺ logged », « Misconfiguration fails loud »).

Réserves : developer preview instable (formats sur disque explicitement sans promesse de compatibilité — copier des mécanismes, jamais des formats de sérialisation) ; biais Node/Cordis fort (porter l'*intention*, pas la syntaxe) ; la moitié du volume `.md` est de l'i18n chinois ou des notes historiques ; **P6/Judge explicitement absent** — le README de `tool-ralph` documente lui-même la limite « Completion is worker self-declaration — no independent evaluator », et `BENCHMARK.md` est quasi vide. Note globale : **🟢 Haute** — non comme code réutilisable mais comme spécification exécutable et documentée des mécanismes exacts que notre plan demande.

- `references/deepseek-harness/vendor/` (Cordis, cosmokit, schemastery rescopés) : écosystème Node non portable. Ignorer.
- `references/deepseek-harness/apps/web` + `packages/client` (UI React) et `references/deepseek-harness/website/` (projection VitePress des docs) : produit/UI. Ignorer.
- `references/deepseek-harness/native/` : addon Node landlock (sandbox Linux-only). Hors scope (P8-bis couvert par OpenSandbox fiche 45).
- `references/deepseek-harness/python/sdk/` (`api.py`, `client.py`, `errors.py`, `models.py`) : **simple driver JSON-RPC stdio** qui spawn le runtime TS bundlé — aucune logique d'agent Python, ne pas en espérer de réutilisation directe.
- `.agents/notes/` : 2/3 du volume `.md` = i18n zh ou notes archivées ; piocher par sujet (les ADRs cités dans les briques suffisent).
- Les 264 `.jsonl` sont des **fixtures de replay de tests**, pas des jeux d'éval — P6 non couvert.
- Developer preview : ne **jamais copier de formats de sérialisation** (SQLite `SCHEMA_VERSION`, `SESSION_FORMAT_VERSION = 0` sans promesse), seulement des mécanismes.
